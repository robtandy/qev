This site runs a modified Qwasm engine and the freely licensed LibreQuake demo. No proprietary Quake game data is distributed. The Git repository contains integration source; compiled runtime files and corresponding-source archives are generated separately for this site.

LibreQuake demo

The demo is the SHA-256-verified LibreQuake v0.09-beta Lite release, plus qev's derived one-grunt test encounter. Artwork, models, textures and sounds use BSD-style licenses; QuakeC gamecode, progs.dat and pop.lmp are GPL-2.0-or-later. The original notices and credits are retained verbatim in the bundled notice, along with the local installer's provenance.
